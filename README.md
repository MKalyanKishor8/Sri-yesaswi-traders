# Sri Yesaswi Traders — Official Business Website

A premium B2B trade portal and corporate website for **Sri Yesaswi Traders**, founded by **M.V SURESH KUMAR**, based in Narsipatnam, Andhra Pradesh, India.

---

## 🌾 About the Business

Sri Yesaswi Traders is a direct farm-source bulk commodity exporter supplying to importers, food processors, and traders across 18+ countries. Specializes in:

- **Rajma Seeds** (Red / Chitra Kidney Beans) — Sortex Cleaned
- **Finger Turmeric** (Double Polished / Salem Grade)
- **Premium Black Pepper** (Whole Bold 550g/l)
- **Raw Green Coffee Seeds** (Arabica & Robusta)
- **Dried Ginger / Sonth Powder**

## ✨ Features

- **B2B Enterprise Login Gate** — auth.html shows first on every visit
- **Google Sign-In (Firebase SSO)** — 1-click authentication
- **Enterprise Registration** — Company name, business type, commodity, destination port
- **Admin Desk Portal** — 2FA PIN clearance for M.V Suresh Kumar & Trade Officers
- **Sourcing RFQ Form** — Pre-fills a mailto with structured procurement parameters
- **Firebase Firestore Database** — Stores users, enterprise profiles, and RFQ submissions
- **Interactive Trade Desk Chat** — Smart keyword-driven commodity assistant
- **Personalized Header** — Shows logged-in user's name and Sign Out button
- **Responsive Design** — Mobile, tablet, and desktop optimized

---

## 🔐 Firebase Setup

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Create a project, enable **Authentication** (Email/Password + Google) and **Cloud Firestore**
3. Copy your Web App config keys into `firebase-config.js`
